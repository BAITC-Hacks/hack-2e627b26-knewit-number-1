# EKT chat widget

React/Vite-каркас чат-виджета для EKT.kz.

Чат отправляет сообщения в Django API. Серверный оркестратор вызывает OpenAI
Responses API и возвращает только проверенные сервером данные каталога; ключ
OpenAI никогда не передаётся в браузер.

## Запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

`VITE_API_BASE_URL` задаёт target dev-proxy (по умолчанию
`http://localhost:8000`). Браузер обращается к относительным `/api/*` и
`/demo/*`, поэтому Django session cookie и CSRF остаются same-origin.

Для ответов модели в окружении backend должны быть заданы `OPENAI_ENABLED=true`,
`OPENAI_API_KEY` и `OPENAI_MODEL`. Используйте новый ключ из секрет-хранилища,
а не значение в файле `.env`.

Production-проверка:

```bash
npm run build
npm run preview
npm run test:run
```

## Demo-состояния

- Обычный запрос отправляется в `/api/dialog/messages` и получает ответ от
  серверного оркестратора.
- Сервер может вернуть найденный товар; количество и кнопка «Добавить» создают
  неизменяемое резюме корзины.
- Резюме подтверждается кнопкой с конкретным `action_id` либо строгой фразой
  `да`, `подтверждаю`, `добавить в корзину`.
- Изменение цены/остатка показывает новое резюме, а после успеха доступны
  фактическое количество и прямая ссылка на корзину.
- Кнопка `Отменить` останавливает текущий запрос в браузере.
- Ошибка сервиса показывает безопасное состояние и `Повторить`.
- `Очистить историю` открывает подтверждение и возвращает новый диалог к приветствию.
- Реальные API-credentials в frontend не добавляются.
