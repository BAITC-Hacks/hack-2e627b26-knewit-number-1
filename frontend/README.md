# EKT chat widget

React/Vite-каркас чат-виджета для EKT.kz.

Чтение fixture-товара и сценарий подтверждения корзины подключены к Django API.
Остальные ответы ассистента остаются демонстрационными и не обращаются к LLM.

## Запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

`VITE_API_BASE_URL` задаёт target dev-proxy (по умолчанию
`http://localhost:8000`). Браузер обращается к относительным `/api/*` и
`/demo/*`, поэтому Django session cookie и CSRF остаются same-origin.

Production-проверка:

```bash
npm run build
npm run preview
npm run test:run
```

## Demo-состояния

- Обычный запрос показывает состояния отправки и формирования ответа.
- Запрос про автомат загружает fixture-товар `900001`; количество и кнопка
  «Добавить» создают неизменяемое резюме корзины.
- Резюме подтверждается кнопкой с конкретным `action_id` либо строгой фразой
  `да`, `подтверждаю`, `добавить в корзину`.
- Изменение цены/остатка показывает новое резюме, а после успеха доступны
  фактическое количество и прямая ссылка на корзину.
- Кнопка `Отменить` останавливает текущий demo-запрос.
- Запрос со словом `ошибка` показывает безопасное состояние ошибки и `Повторить`.
- `Очистить историю` открывает подтверждение и возвращает новый диалог к приветствию.
- Реальные API-credentials в frontend не добавляются; backend adapter будет подключён отдельно.
